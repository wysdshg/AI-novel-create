## 2. 设计铁律（现役，改动必须留证据）

**角色**
1. **两档分工**（治角色漂移的根基）：客观项（出场章、互动关系、势力归属）→ **自动更新**；主观项（性格、信念、地位）→ **只提示不覆盖**。
2. **AI 改动纪律**：AI 抽到的角色变化只写 `pending` 修订（`character_revisions`），作者确认才回写角色卡；回滚本身也留痕。
3. **采纳只应用该修订打算改的字段**（`changed_fields`）——整份快照回写会擦掉后来批准的字段。
4. **反抄袭**：原型只给**功能定位 / 位阶组合 / 性格强度**三种尺度；禁止照抄姓名、门派、具体身份。
5. **新角色必须有具体姓名**；刻意隐藏身份允许代称，但必须带「（待揭晓）」并标记 `name_known=false`，真名出现时归并。
6. 一篇新角色限额：普通 8 / **舞台切换篇 12**（换地图放宽 + 前 2 章先铺人）。
7. 原型检索查询串退化：`slot_desc → slot → 首登场行剧情摘要+名字`。

**模板库（离线管线）**
8. 阈值**跨书 0.75**（0.80 → 跨书组为 0；0.70 → 贪心聚类链式漂移出巨组）；同书内 0.70；成组门槛 `--min-books 2`。
9. **未进跨书组的弧不丢** → `distill-singles` 单独成模板。
10. 摘要批量 **3~10 章/次**（受 TPM 限制；输入是正文，≈2.5k token/章）；批内相邻摘要相似度 ≥0.85 判复制退化 → 不入库转补跑。
11. 弧 v3：**只提切点 + 确定性缝合**（覆盖由构造保证）+ 逐弧写内容；core 100 + 后视 20；末尾残余单列；弧长上界只作提示（大事件篇章 25~40 章正常）。
12. **区间弧模式** `--arc-append`：保留已有弧，只重切「最后一条弧起点 → 全书末尾」（最后一条弧回炉以修正旧边界）。
13. **灌任何新书前必须过滤非正文**（书评/同人/感言/元叙事）——混进去无法追溯剔除。

**工程纪律**
14. 幂等优先：章节生成（同篇同章号/同标题 → 覆盖不新建）、摘要、弧、索引都必须可重跑。
15. 增强能力**失败不许阻断主流程**（原型检索、向量索引、人物关系回注等全部降级返回空）。
16. 改后端代码 → **宿主手动重启**才生效；跑批前先算厂商额度；工具内写库必须**跨进程只读验证落盘**。
17. **不抠搜上下文**（2026-09-17 用户拍板）：主力模型 DeepSeek 与 `Qwen/Qwen3.8-Flash-Next` 都是 **100w 上下文**（魔搭**按调用次数**计费）→ **送入 LLM 的 prompt 内容不做省 token 式截断**。
    仅**逐章摘要**（硅基 qwen3-8b，按 token 计费）需要省，靠**批量打包**自适应控制，**不截正文**。
    三条真实约束：① 中间遗忘 → 关键信息**前置 + 结构化分块**；② 首字延迟（魔搭开思考可达 400s+，prompt 越长越慢）；
    ③ error log / 兜底原文的截断**保留**（那不是 prompt 内容）。

## 3. 现役设计（不可随手改，改动要同步 02/05）

- **离线管线六步**：逐章摘要 → 弧归并(v3) → 跨书凝练 → 单弧兜底 → 角色画像 → 向量回填（详见 05）。
- **模板三路索引**：`plot_template`（模板级）/ `plot_cast`（槽位级）/ `char_archetype`（原型级）；块序契约 `chunk_idx == cast 数组下标`。
- **角色画像**：模板槽位的 12 维性格按 `(book, alias)` 聚合取**中位数**，`spread` 大 = 观测不稳（可能是角色弧光）。
- **建卡链**：计划 `new_chars` → 引入单（`plan_chars`）→ 作者确认建卡 → 写 v1 修订 → 写后摄取持续提 pending 修订。
- **弧与节拍**：`segment_*` 列语义已重定义为「弧内节拍」（列名不变，零迁移）；`plot_distill` 按 `(arc_no, segment_no)` 聚合。
- **角色立体化依赖链**：S1（建卡注入原型）→ S2（代称分流/限额）→ S3（修订表）→ S5（样本库）；S4（常驻配额）独立。
