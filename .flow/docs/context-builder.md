## 为什么做

写第 N 章时，第 1~N-1 章的记忆、全局设定、伏笔状态、相关资料不可能全靠人工挑。

## 解决什么

下一章写之前自动组装上下文：前情记忆 + 全局设定 + 伏笔状态 + Hybrid 混合检索 + 实体关系图，按预算裁剪。

## 怎么实现

- Hybrid 检索：关键词+向量 RRF 融合（k=60）→ rerank 重排（失败静默降级 RRF 序）
- 实体图一跳扩展（entity_graph.py 异构图）
- 按需加载两阶段协议：商讨先报资料清单再答，常识问题短路
- 篇规划任务卡 layer_chapter_plan 注入，P_CRITICAL 永不裁剪
- 🔴 不抠搜上下文（用户拍板）：主力模型 100w 上下文按次计费，prompt 内容不截断
