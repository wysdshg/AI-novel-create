## 二、方法纪律（用户 2026-10-03 定，写入任务单 v2）

- 噪声是**确定性文本模式**：grep/正则定位，**禁止逐章调 LLM API**（全流程零 API 调用）。
- 非正文章节（番外/感言/通知）集中书尾 20~30 章：**AI 看文件名清单直接分类**，不调 API。
- 两道 gate：①盘点报告用户确认 ②扫描报告+正则清单+三类分类用户批准后才动文件。
