# 篇级批量生成面板（P5）

> 状态: completed | 建立: 2026-09-30 | 更新: 2026-09-30 | 上次验证: 2026-09-30（vite build 复验通过 7.07s + pytest 全量单测 542/542；09-20 真实使用迭代：三防修复 + 回执改全文，用户拍板）

## 为什么做

拍板了整篇计划后，逐章手点生成还是累；一键跑完本篇才是闭环。

## 解决什么

页头亮绿色「一键生成本篇（N 章）」→ 逐章自动生成、实时看进度与流式正文、可暂停/终止/重试，断点续跑。

## 怎么实现

- 纯前端编排、后端零改动：逐章循环调单章生成 SSE（article_id + 空 chapter_id → 后端按本篇最大序号+1 接续；prompt_hint 拼该行计划兜底）
- 每章完成 → 往该章对话线程留两条消息（user 生成指令 + ai **正文全文**——2026-09-20 用户拍板，正文从后端拉落库版，不能用流式累积文本，两者可能不一致）
- 续跑对齐：startBatch 先查篇内已有章数跳过前 N 行；批量期间切换小说/篇被拦截
- 三防修复（真机使用发现）：并发重入锁 / 幽灵章对齐 / 中断误判
- 面板：进度表（待生成/生成中/完成·字数/失败·悬停原因/已有跳过）+ 当前章流式滚动区 + 暂停（本章跑完停）/终止（立即断流）/单行重试/重试全部失败
