## 1. 为什么做（病根，不变）

现 cast 在**「概括后再概括」的骨架文本**上提取（原文→逐章摘要→弧归并→跨书凝练→提角色），
四层抽象磨平细节，**天然提不出立体角色**（L4 行为逻辑：语言风格/思维方式/信念）。

后果链（09-20 核查）：`archetype_text()` 缺「位阶：」「性格：」两段 → `char_archetype` 867 块语义无性格
→ plans.py 建卡「功能位参考」返回空 → `fillFromArchetype()` personality/background 自动起草双双失效。

## 3. 字段侧设计

### 3.1 槽位字段全景（cast[] 每项）

```
保留不动：slot / desc / mode / beats / srcs / ranks / traits(12维冻结) / basis
新增 L4：voice（结构化维度[语域/幽默类型/攻防模式/注意力偏向] + sample_refs 2~3条指针）
        behavior_patterns（行为模式 + 标志性小动作/口头禅模式）
        arc_stance_curve（[{beat, stance}] 节拍态度曲线）
        relation_hooks（[{to_slot, kind, attitude}] 带态度的关系钩子）
        contrast（表里反差结构，跨案例归纳）★核心_conflict 同理
        core_conflict（欲望-软肋结构）
        slot_kind（person | goldfinger | entity，可扩展）
```

三仓分配（C1b 并入本机制一次性定）：**台账**（结构化可 diff）/ **向量文本**（archetype_text 扩展版，
块序契约 `chunk_idx == cast 下标` 不变）/ **样本指针**（指 para_ref/源文件，永不复制原文——侵权纪律）。

### 3.2 trait_anchors 校准流程（D3）

```
观测层行为事件（真书，带证据指针）
 → 每维度独立：行为描述统一交 LLM 聚类（「哪些属同等强度」）→ 3~5 档自适应
 → 档位中心映射回 1~7 → 锚点文案从各档代表行为归纳重写（真书行为，禁自造）
 → 用户抽检：自动生成「分档对照页」（每档 2~3 条代表行为），每维度每档随机 yes/no+备注
 → 不过关的维度重聚类，过关冻结
```

- 存储 1~7 整数（旧 164 条 498 组兼容）；双极维度（warmth/honor/mercy）锚点**两端都写行为**
- 注入端渲染锚点描述**不渲染裸数字**；decisiveness/risk 边界在锚点文案中显式区分

### 3.3 goldfinger_refs（15 字段，瘦身版）

```
自由文本×3：name / pattern（归纳重写一段，必写要素：机制运作+代价+天花板+失灵点+组合建议）
            / cost_limit（短）
枚举×8：kind（器物/系统/老爷爷/血脉/面板/模拟器/规则…）  ability_type（资源/信息/战力/回档/
        运气/规则改写/空间/分身）  source_origin（重生/穿越/系统/奇遇/血脉/契约）
        growth（固定/阶梯/任务解锁/反噬升级）  beneficiary（独享/绑定/可共享/上交）
        agenda（无/协助/敌意——角色化金手指张力源）  emotional_payoff（打脸/囤积/捡漏/养成/迪化）
        coupling（低可平移/高需定制——「每天5000w现金→灵石」即低耦合平移）
元数据×4：tags（题材+时代+流派合并多维） / refs（源书元数据） / status / vec
```

设计戒律（调研沉淀）：无脑强=中期必崩→`cost_limit` 必填；世界观契合度→`coupling` 把关；
pattern 复用+域转移+代价重设+专名必换=标准使用姿势（思想/表达二分法，机制不侵权）。

### 3.4 槽位分档字段集（D9）

| 档 | 字段集 |
|---|---|
| 主角位/核心配角位 | 全字段 |
| 功能配角位 | 六件套：slot/desc/mode/ranks + 记忆点（1~2 个标志小动作或口头禅）+ 行为边界（不抢戏/不说破/何时退场） |

## 4. 提取侧设计

### 4.1 六档角色阶梯（D6 核心）

| 档 | 判定 | 产出 |
|---|---|---|
| 0 无关配角 | 出场 <3~5 章 | 不建模板，走通用脸谱（手写十几条打底） |
| 1 断续配角 | 断续 ~10 章、无有效密集段 | 匹配已有模板不新建；找不到才建不完整模板 |
| 2 篇章级 | 有效段 ≥10 章且集中 1~2 篇（篇内出场率≥50% 为主要人物） | 篇章级模板（相关行为联合） |
| 3 卷级 | 多有效段或累计 40~50 章+跨 2+ 篇 | 卷级低概括模板 |
| 4 小说级（非主角） | 累计 100 章+ | 概括生平（只取功能相关行为）→ 单书模板 |
| 5 全书级/主角 | 贯穿全文 | 书评优先；无书评→史记式：AI 分批通读写人物传记→提炼模板 |

阈值全部配置化（3~5/8~10/40~50/100 为初值，跑两三本书看分布再调）。

### 4.2 出场密度算法（间隔容忍游程合并，纯代码 O(n)）

```
输入：全书章序列 s[1..N]（出场=1；别称按「在场共现窗口 2~3 章」兜底）
参数：gap_inner=2~3（段内断点缝合） min_run=8~10（有效段最短） gap_back=4~5（暂离容忍）
流程：连续 1 与 ≤gap_inner 的 0 缝合 → 段长 ≥min_run 为有效段
输出：seg_count / seg_lens[] / gaps[] / total_on / span(篇覆盖数) → 按上表分档
```

被提及≠在场：别人口中的别称不计出场（用户拍板：在场场景真名/别称必然共现，2~3 章窗口兜底，
残余误差进观测置信度字段）。

### 4.3 LLM 分诊（双信号定档）

```
第一层 批内分诊（Flash-Next，20~30 章/批，~90 次/2400 章书）
  输出 JSON：[{角色, 本批出场章, 档位建议, 一句话行为摘要, 别称登记}]
第二层 全书聚合（代码+汇总 LLM）：合并批次 → 密度算法硬指标 ∪ 分诊软判断（剧情重要性）
  → 全书分档清单（防跨批次档位漂移：以聚合为准）
第三层 按档提取（只对档 2+）：篇章级=联合行为 / 卷级=低概括 / 小说级=概括生平 / 全书级=传记
```

成本 ~200 次 Flash-Next/本（网关按次计费）。分诊与逐章概括共享切批调度器（批次大小不同、切分同源）。

### 4.4 观测层与晋升机制

- 观测层常驻（真名主键 `(book, char)`，行为事件+证据指针），**聚合层永远可重算**——换聚合策略不重扫原文
- 角色跨阈值自动晋升：重聚合即完成，观测不用重提
- 合规三层防线：观测层（真名，内部不注入）→ 模板层（匿名化+专名 grep 核账，命中打回）→ 注入层（只读模板层）

### 4.5 contrast/core_conflict 案例库两级（D4）

隐藏反差在原文中不明写（作者设计），单书提取=AI 编造，违反真书纪律。改走：

```
character_cases（名角色案例库，reference_only，不注入；来源=书评/影评/专业解说，筛浓度：长评/高赞）
  → LLM 跨案例归纳（同一反差类型 ≥3 case 合并防倾斜）→ cast 层 contrast/core_conflict 模式（可注入）
```

大众化风险化解：模式层大众化 OK（套路本来就是模板该存的），新颖度由组合产生
（反差模式 × 位阶 × 金手指 × voice）。**contrast 只做静态结构**，心理演变归 arc_stance_curve/篇规划层。

### 4.6 数据源

- 库内 21 本（经典为主）→ 观测层+密度算法全量可跑
- **群像文优先**（用户 10-01 提议）：群像文功能配角层次丰富，单位章节数产出的角色模板密度最高；《赘婿》《绍宋》已入库可作首批验证
- 现代系统流金手指：语料覆盖不足 → 联网调研 seed 已备（贴吧 19+ 类型/橙瓜 2025 题材映射/中国作家网系统文研究）
- 语调分类：网站分区+读者推荐单（读者投票标签）> 人工标注；节奏维度用探针自动（台词密度/问句率）

## 5. 台词库（一表双轴，轨道 A 与 F8 共用）

一行=一条台词事件：`（book, src_file, para, speaker, scene_tag, style_tag, context, vec）`。
场景轴=对话智能体重查询；说话人轴=轻标签（新角色起草起点）。真名直通拍板后，speaker 记真实角色名。
