# 篇规划与批量生成（M7）

> 状态: completed | 建立: 2026-09-30 | 更新: 2026-09-30 | 上次验证: 2026-09-30（pytest 全量单测复验 542/542 通过；P4/P5 真机交互待用户确认，09-20 真实使用迭代三防修复）

## 为什么做

一章一章手点"生成"太累，而且 AI 写整篇时容易忘记前文角色。要先排好整篇的计划再批量写。

## 解决什么

写一章之前先看到整篇计划：每章的节拍、召回哪些老角色、引入哪些新角色（带连续性检查），拍板后一键把本篇逐章生成完。

## 怎么实现

- P1 服务层：口述+模板骨架 → 章级计划，防幻觉剔除不存在的角色
- P2 向量选角：槽位向量库 + 状态门（死人默认不进池）+ 阈值 0.58 真机标定
- P3 连续性：新角色引入单（≤3/篇）+ 篇间交接差集 + 回归理由材料包
- P4 前端 PlanView：计划表格/选角面板/引入单/连续性警告区
- P5 批量面板：逐章循环调单章 SSE，断点续跑、暂停/终止/重试、三防修复
