# 段落写法打磨（W9）

> 状态: in_progress | 建立: 2026-09-30 | 更新: 2026-09-30 | 上次验证: —（2026-09-21 方案作者拍板；测试/真机验证证据待补）

## 为什么做

整章重生成会破坏作者已改好的部分；作者真正想要的常常是"就这几段，写得更好一点"。

## 解决什么

作者勾选若干段（可断续、可全选），AI 按参考语料逐段重写，只动勾选的段。

## 怎么实现

- 一次请求：勾选多少段就打包多少段 + 各自 top-5 参考（魔搭按次计费，100w 上下文一次装下）
- 向量库用块库（280 字 + 段落边界），查询侧同规则切块
- 输出解析：AI 按「【段落 N】」逐段输出 → 按编号映射回原位置；缺失/编号错的段**保留原文**并标注，绝不静默覆盖
- 合规三不变：库内只存向量+定位；输出对参考查重；本地使用不发布
