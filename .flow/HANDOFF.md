## 3. 工作铁律（违反会出真事故）

1. **跑单测必须用项目 venv**：`.venv\Scripts\python.exe -m pytest backend/tests/unit`（当前 **551 全绿** ~19s）。用全局 Python 会因 fastapi 漂移 + 缺 sqlite-vec 假失败 4 例。
2. **判断模块死活 grep ORM 读写点**，不看数据库行数；状态标 ✅ 必须带验证方式+日期。
3. **信任顺序：数据库实况 > 代码 > 文档**。文档会漂移（10-01 一天抓出 10+ 处过时），动手前对库核账。
4. **PowerShell 5 不支持 `&&`**（用 `;`）；复杂参数写临时脚本到 `outputs/`（已 gitignore）跑完删。
5. **收尾四件套缺一不散会**：改 flow 图 → 同步 docs/02、03 → CHANGELOG 一行 → 提交推送。
6. **WIP 上限 1 主线 + 1 支线**。新想法记 to_plan 两分钟了事；废案当天安乐死，不许留给后续 AI 当前置。
7. **改 flow 图后必须 grep flow.json 核实落盘**。⚠️ 10-01 深夜已查清「apply 成功却不落盘」的真根源之一：**flow.json 曾带 UTF-8 BOM，Node CLI 的 JSON.parse 直接失败**——本轮已剥 BOM（原文件备份在 `outputs/_backup_flow_json_bom.json`），**保存 flow.json 时禁止再带 BOM**。
8. **`AGENT_FLOW_ROOT` 语义 = 项目根**（CLI 找 `{root}/.flow/flow.json`）。传 `.flow` 目录本身会静默建出野目录 `.flow/.flow/`（10-01 踩过，已清）。
9. **问题后移要有主人**：挂起必须挂到具体节点/文档下并带触发条件，不许散落成无主欠账。
10. 数据库在 `~\.ai_novel\data\novel_agent.db`（勿动生产数据，测试走 conftest 的 tmp 库）。
11. **LLM 批处理走 MyAPI 网关（127.0.0.1:9377/v1，Key 在 app_configs `llm.gateway_key`）必须流式**——非流式长请求会被 300s 空闲超时 504 掐死（E10 教训在网关侧复现）。网关模型短名：`qwen3.8-flash-next` / `qwen3-8b` / `glm-5.3-flash` / `deepseek-flash` / `BAAI/bge-m3`（F8 P0 分诊用 flash-next，按次计费）。
12. 含反引号/引号的 Python 代码禁止 bash 内联 `-c`（backtick 会被 bash 当命令替换吃掉内容），**必须先写成 .py 文件再跑**。
