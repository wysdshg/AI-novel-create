## 3. 工作铁律（旧 12 条仍有效，见 git 历史 9023ee7^ 版 HANDOFF；今日新增/强调）

1. **Python 只用 `E:\AI小说创作\.venv\Scripts\python.exe`**——且 **`.venv\Scripts\python.exe` 是转发器**：它拉起的真服务进程 CommandLine 显示成系统 Python 路径，**别据此杀进程**（docs/04 A15，本日 PM 亲自踩过误判）。判 venv 用父进程链 / vec0.DLL 加载路径。
2. **`mode=vector` 不能证明 sqlite_vec 在用**（BruteVectorStore 也报 vector）；系统 Python 缺 sqlite_vec 时检索**静默降级不报错**。
3. **`article_plans.updated_at` 等存 UTC**；`article_plans` 有孤儿行（如 `d2d00cf9`）——核账先做外键差集（docs/04 A16，本日 PM 被"行消失"假象坑了一小时）。
4. 批量删除/移动**看文件系统现状核账**，别信返回值（A14）。
5. LLM 批处理走 MyAPI 网关（127.0.0.1:9377）**必须流式**；网关没起 = embedding 全部静默拒连（今天 F84 验收踩过：`E:\MyAPI\start-uniapi.bat` 起）。
6. 复杂引号 Python 先写 .py 文件再跑；PowerShell 5 不支持 `&&`。
7. **执行渠道已变更**：编排台 OpenCode 派单（dispatch.py）停用（限流+模型弱）；现行模式 = **PM 出自带执行任务单（`outputs/task-DEV-*.md`）→ 用户拿去自己开对话执行 → 回执贴回 PM 对话 → PM 验收归档**。任务单必须自包含（目标/背景/验收标准/坑摘录/交付方式）。
8. 收尾四件套：flow 图 → docs/02、03 → CHANGELOG → git 提交；改 flow 后必须 validate_graph。
9. 单测基线 **599 passed**（F4 后）；跑测用 .venv。
